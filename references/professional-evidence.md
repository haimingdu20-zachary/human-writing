# 专业术语、数据与图像证据

## 先区分四种信息

- 原始测量值来自传感器或仪器，例如心率、温度与步数。
- 派生指标由一个或多个测量值计算而来，例如心率变异性与活跃消耗热量。
- 专有评分由厂商算法生成，例如准备度、睡眠与活动评分。写明它属于某个产品体系，不能当成通用医学量表。
- 行动建议是设备对数据的解释，例如减少训练量或提早休息。把它写成建议，不能写成医学结论。

产品页面、论文、用户截图与作者感受可以出现在同一段，必须让读者知道每句话属于哪一类。厂商宣称用“官方称”或“产品页面显示”，研究结果写出研究对象和设备代际。用户体验只归给实际提供这段经历的人。

## 使用术语

第一次出现会影响理解的专业术语时，使用中文名称加英文全称或缩写。紧接着说明它测量什么、单位是什么，以及读者为什么需要知道。后文保留最自然的简称。

不要擅自替行业创造中文译名。存在多种常见译法时，选择读者最熟悉的一种，同时保留英文。普通读者已经理解的词不必全部加英文。

健康科技文章可按下表校准常见术语。

| 术语 | 准确含义 | 写作边界 |
|---|---|---|
| 静息心率 Resting Heart Rate，RHR | 安静状态下每分钟心跳次数，单位通常为 bpm | 对个人趋势的解释通常比横向比较更有意义 |
| 心率变异性 Heart Rate Variability，HRV | 相邻心搏间期变化的统计特征，常见指标包括以毫秒表示的 rMSSD | HRV高低受测量时间、算法和个人基线影响，不能用一个通用阈值判断健康 |
| 光电容积脉搏波 Photoplethysmography，PPG | 通过光学信号观察血容量随脉搏变化 | 它是测量方法，结果会受佩戴、动作、皮肤灌注和环境影响 |
| 体温偏差 Temperature Deviation | 当前夜间皮肤温度相对个人基线的变化 | 它不等于核心体温，也不能单独用于诊断发热或疾病 |
| 个人基线 Personal Baseline | 设备根据连续历史数据形成的个人参照范围 | 写明大致建立周期，不能把人群平均值当成个人基线 |
| 准备度评分 Readiness Score | 厂商结合睡眠、心率、HRV、温度和活动等信息生成的专有评分 | 它属于算法结果，不能当成直接测量值或医学诊断 |
| 活跃消耗热量 Active Calories | 设备根据活动和生理信息估计的非静息能量消耗 | 属于估算值，不能和实验室测量或不同品牌算法直接等同 |

不要为了显得专业把整张表塞进正文。只选择当前判断确实依赖的术语。

## 写完整的数据

引用一个数字前，尽量补齐下面的信息。

- 数值与单位。
- 记录日期或时间窗口。
- 设备型号、软件版本或研究对象。
- 测量状态，例如夜间、静息、运动中或一次冥想期间。
- 比较基准，例如个人过去两周均值、另一台设备或医学对照。
- 来源性质，例如官方页面、同行评议研究、用户截图或作者计算。

研究数字还要检查样本量、样本特征、对照方法与设备代际。旧型号的验证结果只能支持旧型号或相同算法，不能直接证明新型号的全部准确性。厂商参与或资助研究时，在会影响读者判断的地方说明。

保留原材料的精度。原文写“五六天”就保留范围，图表读数只能看到约数就用“约”。不要根据模糊截图补出小数，也不要把相关关系写成因果关系。

进行产品对比时，先统一指标定义、时间范围和单位。Garmin的目标步数与Oura的活跃消耗热量属于不同目标，不能只把两个数字并排就下结论。可以比较它们如何解释数据、是否给出行动建议，以及用户完成操作需要几步。

## 读取图片和截图

收到图片后先查看原图，不根据文件名、用户摘要或缩略图猜内容。逐张记录以下内容。

1. 图号、来源、设备和页面名称。
2. 可见日期、时间范围与用户状态。
3. 标题、图例、坐标轴、单位与高亮区域。
4. 能准确辨认的数值、峰谷、变化方向和比较对象。
5. 图片能够支持的判断，以及它无法排除的其他解释。

含有健康数据的截图先检查姓名、头像、位置、账号和详细健康记录。公开发布前提醒用户裁剪或遮盖不必要的个人信息。

正文不要只写“如下图所示”。先下一个有限判断，再让图片提供证据。图注写清对象、时间和读图重点。可使用下面的形式。

> 图2显示这次记录中静息心率下降时间偏晚。截图本身只能确认当晚的变化，晚餐时间与变化之间的关系仍是用户的推测。

用户提到图号却没有附图时，写成明确占位。

> ［图2待补  Oura夜间静息心率曲线，需要保留日期、时间轴和最低点出现时间］

不为缺失图片编造数值。用户补图以后重新读取并替换占位。

需要根据精确数据制作图表时，使用图表或可视化工具从已核验数据生成。数据图不得使用生成式图片模拟。装饰性配图可以另行生成或检索，不能承担精确数值证明。

## 让专业信息进入自然叙述

优先让术语和数据回答眼前的问题。可以先写作者观察到什么，再解释相关指标，随后给出数字和边界，最后回到他准备怎样行动。不要让每一段都重复同一套模板。

保留专业判断的分寸。用户说冥想时体温下降，可以写成个人观察。只有一张截图时，不能进一步断言某种情绪造成体温下降。设备提示体温高于基线，可以写它发现了偏差，不能把提醒改写成疾病预警。
